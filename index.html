1-Line SDK Integration

Built purely for OpenAI & Anthropic Python clients.

Zero multi-framework callback bloat. Wrapping the underlying OpenAI or Anthropic client protects custom loops, FastAPI backends, and serverless workers alike.

  1. 1
    Install open-source SDK

    pip install brenducate-sdk

  2. 2
    Wrap your sync or async client

    Use wrap_openai or wrap_anthropic once at startup.

  3. 3
    Scope requests by tenant

    Wrap execution in with sentinel.tenant("acme_corp"): and call flush() on Lambda exit.

from openai import AsyncOpenAI
from brenducate import Brenducate, CircuitBreaker, wrap_openai

sentinel = Brenducate(api_key="br_live_...")

# Supports sync OpenAI & AsyncOpenAI + auto-injects stream include_usage
client = wrap_openai(
    AsyncOpenAI(),
    pulse=sentinel,
    circuit_breaker=CircuitBreaker(
        degrade_after_cost_usd=0.25,  # Step down gpt-4o -> gpt-4o-mini
        max_cost_usd=1.50,            # Hard cap kill switch
    ),
)

async with sentinel.tenant("acme_corp"):
    stream = await client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": goal}],
        stream=True,
    )
    async for chunk in stream:
        pass
from anthropic import Anthropic
from brenducate import Brenducate, CircuitBreaker, wrap_anthropic

sentinel = Brenducate(api_key="br_live_...")
client = wrap_anthropic(
    Anthropic(),
    pulse=sentinel,
    circuit_breaker=CircuitBreaker(degrade_after_cost_usd=0.25),
)

# Automatically tracks cache_read / cache_write buckets & .stream()
with sentinel.tenant("acme_corp"):
    with client.messages.stream(
        model="claude-sonnet-4-20250514",
        max_tokens=1024,
        messages=[{"role": "user", "content": goal}],
    ) as stream:
        for text in stream.text_stream:
            pass
sentinel.flush()  # Safe for AWS Lambda & Modal exit

FAQ

Engineering questions answered directly.

Why not just hack a Redis spend counter myself?

A Redis integer counter doesn't handle OpenAI streaming include_usage injection, subtract cached prompt tokens from total prompt tokens, track Anthropic cache creation vs reads, enforce sticky same-family step-downs, or give you a dashboard where anyone on the team can throttle an unprofitable tenant in one click.

Why do you default Smart Degradation to the same model family?

Swapping claude-sonnet-4 → claude-3-5-haiku or gpt-4o → gpt-4o-mini keeps your existing client authentication, tool-call format, and cache_control annotations completely intact. Once a run crosses the soft cap, staying sticky on that fallback model also lets steps 4–8 reuse that model's KV prompt cache.

Will telemetry be lost in AWS Lambda or Modal functions?

No. Alongside our non-blocking daemon batch queue, Brenducate registers an automatic atexit drain and provides an explicit sentinel.flush() / await sentinel.aflush() call for handler teardown.

Does wrapping OpenAI or Anthropic add request latency?

Budget and loop checks execute in memory against synced policy snapshots in under 1ms. If Brenducate's cloud API is ever unreachable, the SDK fails open cleanly so your customer traffic never stops.
